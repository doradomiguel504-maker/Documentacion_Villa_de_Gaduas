# Documentación - Sistema de Inventario Villa de Gaduas

Repositorio oficial destinado al control de versiones, gestión de requerimientos y almacenamiento de evidencias del proyecto formativo para la microempresa **Villa de Gaduas** (panadería y repostería).

## Componente Metodológico

### 1. Enfoque del Proyecto
El desarrollo de este sistema está orientado a solucionar las necesidades operativas y de control de inventarios de la microempresa Villa de Gaduas, abarcando las fases de análisis, especificación de requerimientos y modelado de procesos (BPMN/UML).

### 2. Estrategia de Control de Versiones
Para garantizar la trazabilidad, el respaldo en la nube y el trabajo estructurado, se implementa la herramienta **Git** junto con **GitHub Desktop**, aplicando buenas prácticas de desarrollo:
* **Estructura de Ramas:** Uso de la rama principal (`main`) para versiones estables y producción de la documentación oficial, y una rama secundaria (`testing`) destinada a pruebas de configuración y cambios preliminares.
* **Control de Cambios (Commits):** Registro histórico incremental mediante confirmaciones (*commits*) estructuradas y asociadas a hitos específicos del desarrollo del proyecto.
* **Gestión de Evidencias:** Almacenamiento organizado de diagramas, flujogramas y capturas del funcionamiento operativo del sistema.
